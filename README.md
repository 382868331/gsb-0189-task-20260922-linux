# dqskin —— 双四元数骨骼蒙皮与绑定修正

纯 Python 标准库实现的**双四元数线性混合蒙皮**（dual-quaternion blending /
DLB，Kavan et al. 2008 的经典做法）可复用模块。离线、确定性、无第三方依赖。

- Python 版本：**3.14.7**（仅用标准库，3.10+ 语法即可运行，开发与验收环境为 3.14.7）
- 依赖：**无**。安装 Python 后无需 `pip install` 任何包，不需要网络 / 账号 /
  密钥 / 数据库 / Docker。
- 范围声明：本库只实现本题契约的有限数学子集（4×4 刚体齐次矩阵、单位双四元数、
  ≤32 骨骼的刚性蒙皮），**不**宣称完整行业标准（glTF/FBX 等）兼容，不含动画编辑器。

## 快速验证

```bash
python -m unittest discover -s tests -v   # 必要测试，69 个用例，毫秒级
python demo.py                            # 固定输入演示，约 0.1 秒（上限 8 秒）
```

`demo.py` 真实计算并打印：① 两骨扭转区域（candy-wrapper）下 DLB 与独立矩阵
线性混合（LBS）参考的对比——DLB 保持截面环刚体、LBS 在 85° 时塌缩到
cos 85° ≈ 0.0872；② 三个实际触发的拒绝（负权、零总权、非刚体剪切矩阵）。
无 `sleep`、无预录结果、无压力测试。

## 公开接口

```python
from dqskin import skin, Bone, RigidTransform, SkinResult

RigidTransform(matrix)          # 不可变；4×4 行主序嵌套序列，构造期校验刚体性
Bone(bind, current, parent=None, name=None)
                                # bind/current 为相对父骨骼的“局部”刚体变换；
                                # 根骨骼 parent=None；支持多根（森林）
skin(vertices, bones, weights, normals=None) -> SkinResult
```

- `vertices`：N 个三维点序列（每项 3 个 int/float）。
- `bones`：1..32 根 `Bone`，**bind 与 current 都是局部变换**。算法先沿父链
  累乘得到各自世界变换，再计算相对绑定修正
  `T_i = current_world_i @ inverse(bind_world_i)`。
- `weights`：长度必须等于顶点数。每个顶点支持两种写法：
  - 字典 `{骨骼索引: 权重, ...}`；
  - 对序列 `[(骨骼索引, 权重), ...]`。
  权重必须非负、至少一个为正；同一骨骼索引不可重复。**不要求权重和为 1**，
  内部按总和归一化，因此整体缩放不改变结果。
- `normals`：可选，长度等于顶点数的三维向量序列；刚体旋转只转方向、不受平移影响。
- 返回 `SkinResult(vertices, normals)`：均为不可变元组；未传法向时
  `normals is None`。
- `skin` 是纯函数：不修改任何入参，失败时不产生对外状态变更（无部分写入）。

### 异常层级（均为 `ValueError` 子类）

| 异常 | 触发 |
|---|---|
| `SkinningError` | 全部契约错误的基类 |
| `RigidTransformError` | 末行不为 `[0,0,0,1]`、3×3 部分非正交、行列式 ≠ +1（拒绝缩放/剪切/反射） |
| `SkeletonError` | 骨骼数越界、父索引越界/为负、自环、直接或间接环 |
| `WeightError` | 负权、零总权、空权重、索引越界、重复索引、长度不符、形状错误 |
| `VertexDataError` | 顶点/法向不是三元向量、长度不符、空顶点 |

错误消息一律带**可定位前缀**，例如 `weights[1][0].weight: negative weight ...`、
`vertices[3][2]: value is NaN or Infinity`、`bones[2].parent: index 9 out of range`、
环检测会给出 `bones[0] -> bones[2] -> bones[0]` 形式的环路径。

## 错误语义总则

- 所有数值（矩阵元素、顶点/法向分量、权重）拒绝 `NaN` 与 ±`Infinity`。
- 整数参数（父索引、权重里的骨骼索引）拒绝 `bool`（`True`/`False`，
  Python 中是 `int` 子类），抛 `TypeError`；其他类型不符同样抛 `TypeError`。
- 非法输入显式报错，**不做静默纠正**（不自动正交化坏矩阵、不裁剪负权、
  不重归一化畸形法向）。
- 本算法没有搜索/求解过程，因此不存在“搜索预算耗尽”这一类别；
  “证明无解”对应的输入级情形（如环、非刚体、零总权）一律立即报对应错误，
  二者不会被混淆。

## 算法

1. 校验全部输入（形状、有限数、刚体性、骨骼树、权重）。
2. 父链累乘世界变换（多根森林各自从局部链累乘）。
3. `T_i = current_world_i @ inverse(bind_world_i)`，刚体逆取结构逆
   `(R^T, −R^T t)`。
4. 每个 `T_i` 转单位双四元数 `(q0, qe)`，`qe = ½·(0,t)·q0`。
5. 逐顶点：以**最大权重骨骼**为符号基准；其余骨骼若实部四元数内积
   `<q0_i, q0_anchor> < 0`，则实部双部**同时取反**（`q` 与 `−q` 表示同一变换）。
6. 加权求和后做单位双四元数正交化：实部归一化 `q0/|q0|`，双部减去其在实部上的
   投影 `qe − <qe,q0>q0`（满足 `<q0,qe>=0`）。
7. 还原旋转 `q0` 与平移 `t = 2·qe·conj(q0)`，位置变换为 `R·p + t`，
   法向变换为 `R·n`。

## 误差口径

- **输入刚体容差（契约，固定不外松）**：3×3 部分列正交误差（`R^T R − I`）
  ≤ `1e-9`；行列式与 +1 的偏差 ≤ `1e-9`；末行偏差 ≤ `1e-12`。超差即拒绝，
  不会用宽容差把坏矩阵放行。
- **输出误差（测试断言，输入位置/平移量级 O(1)、旋转任意）**：
  - 一般解析/参考比对：绝对分量误差 **≤ 1e-9**（固定种子随机扫描实测最坏
    ≈ 9e-15，见 `tests/test_properties.py`）；
  - 绑定姿态不动：**≤ 1e-12**；
  - 两骨在 180° 附近（1e-4、1e-7 间距）的最短弧混合：**≤ 1e-8**；
  - 单骨在 π±1e-9：按一般口径 ≤ 1e-9。
- 期望值全部由 `tests/_reference.py` 的**独立**实现给出（罗德里格斯公式、
  朴素 4×4 矩阵乘/刚体逆、经典 LBS 与轴角闭式推导），该文件不 import 被测核心。
  往返一致（交换 bind/current 后复原）只作为补充性质，不用来产生期望值。

## 输入上限

- 骨骼数：**1..32**（接口边界；短演示不穷举上限，测试含 32 根可达）。
- 顶点数：至少 1；无内置上限，但实现为纯 Python 逐点循环，规模仅供离线小题使用。
- 每顶点权重项数：≤ 骨骼数，不可重复；权重可为任意非负有限数（不要求和为 1）。

## 设计取舍

- 矩阵→四元数使用 **Shepperd 分支法**（按最大对角元选轴），旋转角恰在 180°
  时不退化；有测试覆盖一般轴上的精确 π 与 π±1e-9。
- 刚体逆用结构逆而非通用 4×4 求逆，避免近奇异矩阵的误差放大。
- 权重按总和归一化 → 整体缩放不变（有专门测试，尺度覆盖 0.01..100）。
- 支持多根森林；父链按拓扑染色解析并报告具体环路径。
- 选择“最大权重骨骼”作符号基准（题面指定策略），不引入额外的全局相位选择。

## 已知限制

- **对跖非唯一**：两根骨骼的相对旋转在旋转流形上恰好相差 180°（实部四元数
  内积恰为 0）时，两点之间存在无穷多条等长“最短路径”，几何上没有唯一中点。
  本实现不会崩溃或静默给出 NaN——最大权重骨骼的符号基准保证实部混合模长
  严格为正（≥ 锚点归一化权重），结果确定可复现；只是该结果遵循题面指定的
  “最大权重骨骼为符号基准、并列时取较小骨骼索引”约定，不代表唯一正确姿态。
  180° **附近**（测试覆盖到 1e-9 间距）给出连续、正确的最短弧结果。
- 只接受刚体变换；缩放、剪切、反射一律拒绝（`det = +1`）。
- 纯 Python 标准库实现，未做向量化；无动画编辑器、关键帧、文件导入导出。
- 法向按刚体旋转方向直接变换（无逆转置需求，因为不存在缩放/剪切）；
  输出不归一化法向，长度与输入一致。
